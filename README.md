프롬프트 작성을 더욱 상세히 한다. 예) [네 임의대로 구현하지 말고 Figma의 보이는 화면과 동일하게 처리해. 다른 건 추가하지말고 시안과 다르게 해야 할 것이 생기면 먼저 물어봐.]
